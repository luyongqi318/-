# 云部署说明

三种方式，按“要不要自己的服务器”排序。

---

## 方式一：阿里云 / 腾讯云 ECS（推荐，数据在自己手里）

### 1. 买服务器

| 项 | 建议 |
| --- | --- |
| 机型 | 2 核 4G 起步（阿里云 ecs.e-c1m2.large / 腾讯云 S5.MEDIUM4） |
| 系统 | Ubuntu 22.04 LTS 64 位 |
| 磁盘 | 40G 系统盘够用（数据库只有几 MB） |
| 带宽 | 3–5 Mbps 足够内部使用 |
| 安全组 | 放行 **22 / 80 / 443**；3000 只在调试时临时开 |

### 2. 上传代码

在本地项目目录执行（把 IP 换成你的服务器）：

```bash
# 方式 A：有 Git 仓库
ssh root@服务器IP "mkdir -p /opt/doubletree-hr"
git clone <你的仓库> /opt/doubletree-hr

# 方式 B：没有仓库，直接传（排除 node_modules / release / data）
scp -r Dockerfile docker-compose.yml package.json package-lock.json tsconfig.json next.config.* \
       src public scripts deploy .env.example root@服务器IP:/opt/doubletree-hr/
```

> Windows 上可用 WinSCP 拖拽，效果一样。

### 3. 一条命令起站

```bash
ssh root@服务器IP
cd /opt/doubletree-hr
bash deploy/deploy.sh
```

脚本会：装 Docker → 生成 `.env`（自动写随机 `AUTH_SECRET`）→ 构建镜像 → 启动 → 健康检查。

### 4. 改密码、填 Key

```bash
nano /opt/doubletree-hr/.env
# HR_PASS=你的强密码
# DEEPSEEK_API_KEY=sk-...
docker compose up -d
```

模型 Key 也可以在网页「系统设置」里填，效果一样。

### 5. 域名 + HTTPS

```bash
apt install -y nginx certbot python3-certbot-nginx
cp /opt/doubletree-hr/deploy/nginx.conf /etc/nginx/sites-available/hr
ln -s /etc/nginx/sites-available/hr /etc/nginx/sites-enabled/hr
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

# 域名解析到服务器 IP 后：
certbot --nginx -d hr.example.com
```

之后访问 `https://hr.example.com`（80/443 走 Nginx，应用只监听本机 3000）。

### 6. 每日自动备份

```bash
chmod +x /opt/doubletree-hr/deploy/backup.sh
crontab -e
# 加入：
0 3 * * * bash /opt/doubletree-hr/deploy/backup.sh >> /var/log/hr-backup.log 2>&1
```

备份在 `/opt/doubletree-hr/backups/`，保留最近 14 份。

### 7. 以后更新

```bash
cd /opt/doubletree-hr && git pull && docker compose up -d --build
```

数据在 `./data/hr.db`，容器重建不会丢。

## 方式二：Railway / Render（不用自己运维）

仓库里已经有 `railway.json`、`render.yaml`。

- **Railway**：新建项目 → Deploy from GitHub → 添加 Volume 挂到 `/app/data` → 环境变量填 `HR_PASS`、`AUTH_SECRET`、`DEEPSEEK_API_KEY`。
- **Render**：New Web Service → 选仓库 → 系统自动读 `render.yaml` → 添加 Disk 挂 `/app/data`。

两者都要求代码在 GitHub。免费额度会休眠，正式用建议最低档付费实例。

## 方式三：临时公网链接（今天就能看）

本机跑着服务时开一条 Cloudflare 隧道：

```powershell
cloudflared tunnel --url http://localhost:3000
```

会给一个 `https://xxx.trycloudflare.com`。**缺点**：电脑关机就失效，地址每次变，只适合演示。

## 部署前检查清单

- [ ] `HR_PASS` 改成强密码（默认 `doubletree2026`）
- [ ] `AUTH_SECRET` 是随机长串（deploy.sh 会自动生成）
- [ ] 模型 Key 填好并点过「测试连接」
- [ ] 安全组只开 22/80/443，别把 3000 暴露到公网
- [ ] 备份 cron 已加
- [ ] 数据库从本地带上来的话，用页面「导出/导入」或直接传 `data/hr.db`
